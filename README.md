# NexusBot

A custom Discord bot built for community management and automated updates.

## Privacy Policy & YouTube API Compliance
- **Data Collection**: NexusBot does not store or collect personal user data.
- **YouTube API Usage**: NexusBot uses YouTube Data API Services to automatically check for new video releases and send updates to designated Discord channels.
- **Terms & Privacy**: By using NexusBot, users agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](http://www.google.com/policies/privacy).
- **Data Deletion**: Since no personal user data or YouTube data is permanently stored, no user data deletion requests are necessary.
